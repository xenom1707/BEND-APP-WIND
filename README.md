# Bend Calculator V3 - Windows

GitHub Actions builds a portable Windows EXE.

## Build
1. Upload the entire repository structure to GitHub.
2. Open Actions.
3. Choose **Build Windows EXE**.
4. Click **Run workflow**.
5. When the run is green, download **BendCalculator-Windows-EXE** from Artifacts.
6. Extract the ZIP and run the EXE.

The app stores its local browser/Electron data on the Windows user profile. Use the JSON backup/export feature for portable backups.
